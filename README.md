# 数控刀具寿命闭环

统一记录数控刀具从入库、装刀、加工、调拨、修磨、孪生接管到报废的完整生命周期。
刀具**身份与机床刀位分离**，任何调拨都不重置累计加工证据；所有状态都是哈希链
事件日志的重放派生品，进程重启后逐字节一致地重建，不存在分叉。

## 它解决什么问题

- 刀具在机床/厂区间调拨后寿命计数被清零、重新开始 → 身份级累计计数随刀走，
  调拨只允许在库态进行，且不改任何计数。
- 孪生刀补位后没人能证明"为什么允许继续生产" → 接管只换主轴身份，**不自带
  授权**；新主刀必须凭自己的计数重新取得开工许可，授权与规则版本全部留痕。
- 断刀时刻的主轴负载异常没有独立核算 → 件数、切削秒数、异常冲击三条寿命
  独立核算，负载比越冲击阈值计冲击分，严重冲击（spike）一刀即硬限。
- 规则改了之后旧账说不清 → 规则按 `零件 × 材料 × 刀具规格 + 生效区间`
  版本化，开工时把整份限制快照**钉版**进授权事件，成品追溯直接给出规则版本。
- 旧机床迟到回执被当作实时数据 → 离线补报一律隔离进复核队列，工艺主管签字
  后才入账；旧刃磨周期的回执只补身份级证据，不动当前寿命。

## 授权结论（开工闸门）

| 结论 | 含义 |
|---|---|
| `allowed` | 可开工（计数在预警值以下，或适用范围+签字齐全的人工放行） |
| `finish_current_cut` | 已达预警值：允许完成当前切削，本刃磨周期仅一次 |
| `denied` | 越过硬上限 / 收尾机会已用 / 刀具状态不允许（硬上限不可被任何放行覆盖） |
| `manual_review` | 该零件×材料×规格在当前时刻无生效规则 |

刀具状态机：`available / mounted / warning / blocked / grinding / retired`，
换刀、调拨、修磨、报废、孪生接管全部走同一张合法迁移表（命令路径与日志重放
共用），非法迁移在写入前即被拒绝。

## 角色边界

- **工艺主管 supervisor**：发布规则、跨厂调拨、修磨结案、报废、复核离线回执、
  人工放行（必须写清刀具/零件/材料/件数/期限范围并签字）、成品事故回溯。
- **班组长 foreman**：扫码装/换刀、绑定孪生、送修；只看待换刀队列。
- **机床 machine**：申请开工、上报切削回执、提交离线补报。

## 架构

```
命令(校验+状态机预演) ──► EventStore(append-only, 哈希链, JSON 持久化)
                                  │
                                  ▼
                          projector.fold 重放
                                                  ├─ Tool(周期计数/全寿命累计/位置/孪生角色)
                                                  ├─ Machine(刀位占用/水位线)
                                                  ├─ TwinPair(主备/接管历史)
                                                  ├─ Permit(钉版规则/结论) / Override(范围+签字)
                                                  ├─ PartRecord(成品→每刀→规则版本)
                                                  └─ 复核队列
```

- `app/domain.py`     常量与异常（取值对齐 `domain_contract.json`）
- `app/events.py`     事件类型与哈希链
- `app/store.py`      append-only 日志存储（业务编号幂等、篡改可检出）
- `app/state_machine.py` 合法状态迁移表
- `app/rules.py`      生效期版本化规则、三计数器评估、冲击计分
- `app/models.py`     重放态模型
- `app/projector.py`  事件折叠（重放投影）
- `app/service.py`    命令/授权/复核/孪生接管应用服务

## 运行

```bash
python3 -m unittest discover -s tests -v   # 22 个领域测试
python3 demo_lifecycle.py                  # 调拨→修磨→离线补报→孪生接管全链路演示
```

演示结束前会"杀掉进程"，仅用日志文件独立重建两次并逐字段比对：剩余寿命、
开工许可、待换队列、成品追溯与关停前完全一致。
